# ASUS_UX305LA_driver
check bios version and ASUS notebook model, batch file

```
wmic bios get smbiosbiosversion > out.txt

wmic csproduct get name >> out.txt

```

output
```
SMBIOSBIOSVersion  
UX305LA.300        

Name     
UX305LA
```
